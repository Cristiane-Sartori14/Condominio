# 🏢 Sistema de Condomínio

> Aplicação web para gerenciamento de condomínios desenvolvida em grupo no curso de Análise e Desenvolvimento de Sistemas (ADS).

---

## 🏢 Sobre o projeto

Aplicação desenvolvida em grupo durante o curso de Análise e Desenvolvimento de Sistemas (ADS), com foco na criação de um sistema de gerenciamento de condomínio.

A aplicação permite gerenciar moradores, unidades e pagamentos, proporcionando organização, controle e praticidade na administração condominial.

---

## ⚙️ Funcionalidades

- Cadastro de moradores
- Controle de visitantes
- Organização de informações do condomínio
- Recebimento de encomendas
- Reservas salões festas entre outras funcionalidades

---

## 🛠️ Tecnologias utilizadas

### Backend
- Java
- Spring Boot (desenvolvimento de APIs REST)

### Frontend
- Angular
- JavaScript / TypeScript

---

## ▶️ Como executar o projeto

```bash
# Clone o repositório
